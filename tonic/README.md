# hōlus experimental brand concept

This directory is a standalone brand comparison. It displays the current somaē website exactly as maintained by the production wrapper and changes only the visible brand name to `hōlus`. It does not modify the production somaē pages, styles, scripts, branding configuration, routing, content, or assets.

## Local preview

Serve the repository root with any static HTTP server, then open `/tonic/`.

Example route when the existing local preview runs on port 4180:

`http://127.0.0.1:4180/tonic/`

## Comparison scope

All homepage content, credentials, imagery, contact actions, services and navigation are inherited from the current somaē site. The only experimental change is the visible brand name.
